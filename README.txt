TANAY & ARPITA — WEDDING INVITATION WEBSITE

PHONE-FRIENDLY UPLOAD
1. Extract this ZIP on your phone using Files / My Files.
2. In Chrome, sign in at https://github.com
3. Create a NEW PUBLIC repository named: tanay-arpita-wedding
4. Open the repository, choose Add file > Upload files.
5. Upload the CONTENTS of this folder (index.html, style.css, script.js, images folder, music folder). Make sure index.html is at the repository's top level, not inside another folder.
6. Commit the upload.
7. Open Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select branch main and folder /(root), then Save.
10. Wait a few minutes. Your site address will look like:
    https://YOUR-GITHUB-USERNAME.github.io/tanay-arpita-wedding/

EDIT THE DETAILS
- Venue and time are placeholders in index.html. Replace them when confirmed.
- The countdown currently uses 6:00 PM India time as a temporary reference. Change the time in script.js once the actual ceremony time is known.
- Add couple photos named exactly couple-1.jpg and couple-2.jpg inside images/.
- Add an instrumental MP3 named bengali-instrumental.mp3 inside music/. Use audio you have permission to share. Music starts only when a visitor taps Play music.

IMPORTANT
- This is a public website: anyone with the link can view it.
- Get the couple's permission before uploading their photos.
- GitHub Pages is free for public repositories on GitHub Free.
- The map link is not included yet because the venue is not confirmed.
